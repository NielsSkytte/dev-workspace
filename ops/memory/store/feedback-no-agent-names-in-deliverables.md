**Rule 1: Never mention agent names in deliverables or customer-facing outputs.**
Internal persona names (`M`, `Q`, `fabric-back`, `sentinel`, etc.) are operational LLM roles for workspace automation. Deliverables, design docs, HTML reports, SoWs, status check-ins, and customer-facing files must **never** mention agent names (e.g. use "CURRENT ENGINEERING FOCUS" instead of "Agent M Continuity Note").

**Rule 2: Never use handwritten/cursive fonts (Ink Free) in formal architecture diagrams.**
`Ink Free` is strictly for informal creative highlights, standouts, or annotations — never for technical callout boxes or note bodies in executive architecture documents. Use clean `Aptos` / `Aptos Display` instead.
