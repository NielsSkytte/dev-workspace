Context: the DataCompare app card "How this comparison works". Draft one was 18 narrative
sentences; the owner said "less AI, short and to the point"; draft two was 14 shorter sentences,
still prose; the owner said "make it boring type instruction text". Draft three, labelled
statements ("Systems: MFO (vendors) and GFO (vendors). Snapshot date: 7 Sep 2026. Master: MFO."),
was accepted without comment. Same for rule entries ("Field: ... Legal entities: ... MFO value:
... Created by ... Reason: ... Status: ...").

Rule for next time: when text will sit inside a tool for any reader, start at draft three.
The reader being a customer is not the condition -- 2026-09-22, the Today page's hints and tile
feet read as narration to Niels on his own dashboard (see `eval-20260922-today-page-ask-text`). The writing-voice economy rule applies, and beyond it: no sentences that connect
facts, only facts with labels. Headings likewise: "Method", "Rules", not "How this comparison
works, and the rules in force, in plain language".
