**User:** the activity says queued, is there not a way to get it started

**Assistant:** No, there's no way to force it. Customer Insights runs its jobs in sequence, and the activity queues behind whatever is already running.

**Check what's blocking it:** **Settings → System → Status**. Look for a data source refresh, a unification run or a measure that's still in progress. The activity starts when that finishes.

**Typical durations here:** unification over 24,000 profiles is minutes; a Power Query refresh of 4.4 million invoice rows is the slow one and likely what it's waiting on.

**If it sits at Queued for more than an hour with nothing else running,** that's a platform issue, not a setup issue. Refreshing the browser sometimes shows the real state, since the page caches.
